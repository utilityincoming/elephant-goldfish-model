# site Blueprint

## System Overview

The static landing site for the Elephant-Goldfish Model, served at
https://egm.dev and built with Astro (+ Starlight for docs). It renders the
marketing page and a documentation set sourced from the repository's
`docs/site/**` Markdown, exports per-page plain-Markdown for LLM consumption,
and ships privacy-gated Google Analytics that only activates on the canonical
host. A human-readable guide also lives in [`README.md`](./README.md).

## Local Interface & Invariants

- `astro.config.mjs` — Astro build configuration (site URL, Starlight
  integration, `/docs/*` redirects, the `starlight-llms-txt` plugin, a custom
  Markdown processor using `remarkRepositoryLinks`, and self-hosted local fonts so
  the page never calls `fonts.googleapis.com`). Direct source at the subsystem root.
- `package.json` — defines the build/test scripts: `test` (`node --test`),
  `test:browser`, `check`, `check:docs`, `capture`, `dev`, `build`, `preview`.
- Requires Node `>=22.23.4` (`package.json` `engines`).
- `PUBLIC_GA_MEASUREMENT_ID` is the only analytics switch; unset disables
  telemetry entirely (see `src/layouts/EGM.md`).

## Subdirectories & System Boundaries

- src: [./src/EGM.md](./src/EGM.md) — the Astro application source (content config,
  pages, layout, components, lib).
- scripts: [./scripts/EGM.md](./scripts/EGM.md) — image capture and `dist/`
  verification scripts driven through npm.
- public — static assets served at the site root (favicons, generated `og.png`);
  no code contract.
- screenshots — committed preview images regenerated by `scripts/capture.mjs`;
  no code contract.
- tests — Node test fixtures; excluded from contract generation.

## Global Invariants

- Analytics loads only when `PUBLIC_GA_MEASUREMENT_ID` is set and the runtime host
  is `egm.dev`; forks, previews, and local builds never contact Google.
- Repository-relative links in exported Markdown are rewritten to absolute GitHub
  URLs, and any reference escaping the repository root is rejected at build time
  (`src/lib/repository-markdown.mjs`).
- Build/test scripts assume npm runs from `site/` (the repo root is resolved as
  `..`).

## Global Side Effects

- Build-time network: one GitHub API request for the star count per build
  (`src/lib/github-stars.ts`).
- Runtime network (canonical host only): Google Cookie Notification Bar and GA4,
  after affirmative consent.
- Filesystem: `scripts/capture.mjs` overwrites `public/og.png` and
  `screenshots/*.png`.

## System Verification

- Run: `npm test` (from `site/`); additional checks: `npm run check`,
  `npm run check:docs`, `npm run test:browser`
